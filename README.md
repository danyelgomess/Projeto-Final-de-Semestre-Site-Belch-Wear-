# Belch Wear
Belch Wear é um site de loja online de roupas streetwear desenvolvido como projeto final de semestre da faculdade. O projeto simula um e-commerce funcional, com foco em layout moderno, responsividade e organização do código.

## Funcionalidades
- Página inicial com destaque de produtos
- Menu responsivo
- Carrossel de imagens
- Estrutura de loja virtual
- Layout adaptado para desktop e mobile

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Swiper.js

## Estrutura do projeto
- index.html
- login.html
- style.css
- login.css
- script.js
- /images

## Contexto acadêmico
Projeto desenvolvido para fins acadêmicos no curso de Análise e Desenvolvimento de Sistemas, com o objetivo de aplicar na prática conceitos de desenvolvimento front-end.
